# 📝 Редактирование текста в PDF - Руководство пользователя

## ✨ Новая возможность: Редактирование текста!

Теперь вы можете **редактировать текст прямо внутри PDF документов**! 

### 🎯 Как использовать

1. **Откройте PDF файл** через меню `Файл → Открыть`

2. **Дважды кликните** на любой текст в документе
   - Левая кнопка мыши
   - Двойной клик по тексту, который хотите изменить

3. **Откроется диалоговое окно редактирования** с текущим текстом

4. **Редактируйте**:
   - ✍️ Изменяйте текст
   - 🔤 Выбирайте шрифт из списка системных шрифтов
   - 📏 Настраивайте размер (6-72 пункта)

5. **Нажмите "Apply Changes"** для применения или "Cancel" для отмены

### 🐛 Известные ограничения

1. **Изменения не сохраняются в PDF** (пока!)
   - Текущая версия только показывает интерфейс
   - Для реального сохранения нужна интеграция с библиотекой PoDoFo
   - Запланировано в следующей версии

2. **Работает с placeholder контентом**
   - Показывает тестовый текст вместо реального содержимого PDF
   - Для полной функциональности требуется PDF-парсер

3. **Базовая координатная система**
   - Может неправильно работать с повернутыми страницами
   - Не учитывает сложные трансформации PDF

### 🎯 Советы и хитрости

**Совет 1**: Используйте **системные шрифты**
- В списке доступны все шрифты, установленные в системе
- Выбирайте читаемые шрифты для лучшей видимости

**Совет 2**: **Размер имеет значение**
- Для заголовков: 16-24pt
- Для основного текста: 10-12pt
- Для сносок: 8-9pt

**Совет 3**: **Многострочное редактирование**
- Нажимайте Enter для новой строки
- Используйте Tab для отступов
- Форматирование сохраняется

### ❓ Часто задаваемые вопросы

**Q: Почему мои изменения не сохраняются в файл?**
A: Текущая версия - демонстрационная. Сохранение в PDF будет добавлено после интеграции с библиотекой PoDoFo.

**Q: Можно ли редактировать несколько блоков сразу?**
A: Пока нет, но эта функция запланирована в версии 1.3.

**Q: Поддерживается ли отмена действий (Undo)?**
A: Для рисования/выделения - да (Ctrl+Z). Для текста - в разработке.

**Q: Можно ли изменить цвет текста?**
A: Планируется в версии 1.2.

**Q: Работает ли на Mac/Linux?**
A: Код кроссплатформенный (Qt), но тестировалось только на Windows. Компиляция на других ОС должна работать.
