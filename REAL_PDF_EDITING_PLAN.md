# План реализации реального редактирования PDF

## Анализ Stirling-PDF
- **Архитектура**: Java Spring Boot + React Frontend
- **PDF библиотека**: Apache PDFBox (Java)
- **Подход к редактированию текста**:
  1. PDF → JSON конвертация (извлечение текста, шрифтов, координат)
  2. Редактирование JSON в веб-интерфейсе
  3. JSON → PDF конвертация (пересборка PDF с новым текстом)

## Наш C++ подход

### Выбор библиотеки
**PoDoFo** - лучший вариант для C++:
- ✅ Полное редактирование PDF (текст, изображения, метаданные)
- ✅ Работа со шрифтами
- ✅ Поддержка всех версий PDF
- ✅ Open Source (LGPL/GPL)
- ✅ Активная разработка

**Альтернативы (не используем)**:
- PDFium - только рендеринг, нет редактирования
- MuPDF - ограниченное редактирование
- QPDF - манипуляции структурой, но сложное редактирование текста

## Преимущества перед текущей реализацией

### Текущая (аннотации поверх):
- ❌ Не изменяет оригинальный текст
- ❌ Аннотации видны как слой
- ❌ Нельзя редактировать существующий текст

### Новая (реальное редактирование):
- ✅ Изменяет оригинальный текст в PDF
- ✅ Невидимое редактирование
- ✅ Полный контроль над текстом
- ✅ Как в Adobe Acrobat

## Примерный код (концепт)

```cpp
// Извлечение текста
TextExtractor extractor(pdfDocument);
QVector<TextBlock> blocks = extractor.extractTextBlocks(pageIndex);

// Редактирование текста
for (auto& block : blocks) {
    if (block.contains(clickPos)) {
        QString newText = showTextEditDialog(block.text);
        TextEditor editor(pdfDocument);
        editor.replaceText(pageIndex, block, newText);
        break;
    }
}

// Сохранение
pdfDocument->save(filePath);
```
